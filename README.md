# AI 台灣旅遊情報員 × 智慧行程推薦網站

以每週旅遊情報吸引旅客，再依旅客偏好整理台灣旅遊提案，服務親子、情侶及熟齡旅客。本專案將「工作角色」視為交接分工；不需要多 Agent 才能執行。

## 專案內容

- **旅遊情報：** 整理 9 筆景點資料，附來源 ID、查詢日期、適合客群建議與待確認限制。
- **週報：** 根據研究資料編輯親子、情侶與熟齡旅遊情報及業務訓練內容。
- **網站：** 單檔 HTML、CSS、原生 JavaScript。依旅伴和風格做可解釋的規則式推薦，支援「雨天優先」排序並可複製諮詢需求。
- **簡報：** 提供可瀏覽的 HTML 投影片與 PPTX 檔。
- **影片：** 提供分鏡、影片生成提示詞及一支 10 秒 FFmpeg 成片。

## 開始使用

1. 以瀏覽器開啟專案根目錄的 `index.html`。
2. 選擇旅遊對象、每人每趟預算、天數及旅遊風格；可選擇開啟「雨天優先」。
3. 查看推薦理由、來源與待確認資訊，或複製諮詢需求摘要。

網站不使用 AI API、資料庫或 Supabase，表單偏好只在目前頁面執行，不會送出或保存。

## 驗收與測試

需要安裝 Node.js。於專案目錄執行：

```sh
node acceptance/test-index.cjs
```

目前 Node VM 功能回歸為 10/10 通過。測試涵蓋景點資料、規則式推薦、雨天排序、無匹配提示、需求複製及響應式 CSS 規則。實際瀏覽器外觀、不同裝置尺寸和鍵盤操作狀態見 [`acceptance/website-index.md`](acceptance/website-index.md)。

## 資料限制與發布原則

- 旅遊研究資料及來源查詢日期：**2026-10-28**。週報報導期間：2026-10-22 至 2026-10-28。
- 景點客群適配是研究員建議，不是官方認證。雨天分類只標記來源明載的室內資訊：動物園為「部分室內」、臺北 101 觀景台為「室內」；其他 7 筆的雨天適配為「待確認」。這不代表當日開放、全程遮雨或官方雨天推薦。
- 目前沒有正式旅行社行程、票價、住宿或交通成本，也沒有可核實的行程天數。網站只呈現景點提案，不承諾符合預算、可訂位、成團或活動正在舉辦。
- 價格、活動、交通、營運、開放與安全資訊須在發布、報價或出發前回到官方來源重新確認，標示來源及查詢日期。
- `video/assets/taiwan-triptych.png` 與影片中的人物和場景是 AI 情境示意，不是景點實拍。10 秒影片使用 FFmpeg 組合示意圖、字幕及合成氛圍音，沒有語音旁白。
- 「島嶼日常」是示範品牌，不代表實際旅行社或正式商品。

## 隱私與憑證

不要在 HTML、文件、測試資料或 Git 中放入帳號密碼、API Key、存取權杖、真實旅客個資或內部成本。`.env`、本機憑證與 FFmpeg 中間素材由 [`.gitignore`](.gitignore) 排除。若未來需要憑證，使用伺服器端環境變數，勿將秘密放進前端。

## 角色流程

旅遊研究員 → 週報編輯 → 簡報企劃／影片企劃 → 網站工程師 → 驗收員。詳細責任、輸入、交接及驗收標準見 [`AGENTS.md`](AGENTS.md)；產品需求見 [`docs/PRD.md`](docs/PRD.md)。
